# Historical baseline

The removed pre-migration implementation used classical 3D blob detection, greedy
nearest-neighbour tracking, and a heuristic division post-pass. Its recorded public score was
approximately **0.543** (earlier notes rounded this to 0.55).

The implementation remains recoverable from Git history and local tag `legacy_baseline` at commit
`6f7c40161309b7f48e846edd508af401ffd8de18`. No historical result file was present in this Windows
checkout, so none was deleted or overwritten.
